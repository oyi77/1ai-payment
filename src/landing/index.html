FAQ

Apa yang terjadi jika gateway mati?What if a gateway goes down?
Integrasi Anda gateway-agnostic: ganti parameter gateway di payment request, transaksi lewat backup. Kode checkout tak pernah berubah. Your integration is gateway-agnostic: change the gateway parameter, transactions route via backup. Checkout code never changes.
Di mana data saya disimpan?Where is my data stored?
Database LibSQL di infrastruktur kami, terisolasi per merchant. Kami mencatat event ternormalisasi (order_id, status, amount) — bukan payload gateway mentah. Tak ada API key tersimpan plaintext. LibSQL on our infrastructure, scoped per merchant. We log normalized events (order_id, status, amount) — never raw gateway payloads. No plaintext API keys.
Apakah ini relevan dengan PCI?Is this PCI-relevant?
Kami tak menyimpan, memproses, atau mentransmisikan nomor kartu. Data bayar langsung pelanggan → gateway; kami hanya terima payment URL + status callback. Konsultasikan QSA Anda untuk implementasi spesifik. We never store, process, or transmit card numbers. Payment data goes customer → gateway; we only receive payment URLs + status callbacks. Consult your QSA for specifics.
Bisa white-label untuk klien?Can I white-label for clients?
Ya — API key merchant-scoped + rate limit terisolasi dibuat untuk itu. Hubungi kami untuk agency pricing. Yes — merchant-scoped keys + isolated rate limits are built for it. Contact us for agency pricing.
